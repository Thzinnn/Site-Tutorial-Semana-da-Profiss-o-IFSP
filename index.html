Instruções para Jogar

Para Andar

Para Frente(PF)

Exemplo: pf 100

Para Trás(PT)

Exemplo: pt 100

100 é o número de passos, ele define a distância que você vai andar

Para virar

Para Direita(PD)

Exemplo: pd 90

Para Esquerda(PE)

Exemplo: pe 90

90 é o número de graus, se for 90 ele vira para o lado, se for 180 ele vira para trás e se for 360 ele dá uma volta

Comandos Adicionais

Use Nada(UN)

Serve para sua tartaruga parar de escrever a linha

Use Lápis(UL)

Serve para sua tartaruga voltar a escrever a linha

TAT

Limpa a tela inteira

Desafios de Programação

Faça a tartaruga desenhar um quadrado.
Cada lado deve ter 100 passos. A tartaruga deve terminar no ponto onde começou.

Faça a tartaruga desenhar uma escada com 3 degraus.
Cada degrau deve ter: 50 passos de comprimento e 30 passos de altura.

Faça um desenho utilizando três formas geométricas simples
Um quadrado no lado esquerdo da tela.
Um triângulo no lado direito da tela.
Um hexagono no centro, entre o quadrado e o triângulo.
As três formas devem ficar separadas e formar uma composição organizada.

Faça a tartaruga desenhar a primeira letra do seu nome.
Desafio extra:
A letra deve ser formada apenas por linhas retas.
Tente fazer a letra com o menor número possível de movimentos.

Faça um desenho ou forma da sua escolha
Esse é o desafio final, use sua imaginação e utilizando o que você aprendeu, utilize a tartaruga para fazer algo da sua escolha
